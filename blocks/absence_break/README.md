# Absence Break Block

בלוק עצמאי בין חיישן הקרבה לבין VibeBar:

`NEAR/FAR/DISCONNECTED → five-minute gate → BreakWriter`

הפסקה נכתבת רק לאחר חמש דקות רצופות, אך מקבלת את זמן היציאה המקורי. חזרה מוקדמת
מבטלת אותה. ברירת־המחדל היא `NullBreakWriter`, ולכן חיווט חסר אינו משנה את היומן.

`absence_break.live` היא נקודת ההרכבה היחידה: היא מחברת את קורא ה־JBL, מנוע הקרבה,
מנוע חמש־הדקות וכותב היומן. מצב `UNKNOWN` של החיישן נזרק ואינו יכול ליצור הפסקה.
